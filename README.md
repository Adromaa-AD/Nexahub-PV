🎨 Design Philosophy

NEXA-ORBIT follows a premium, clean, and modern visual direction:

- Ivory and pearl-white surfaces
- Soft blue and lavender accents
- Elegant dark typography
- Subtle glass effects
- Thin borders
- Soft shadows
- Smooth rounded interfaces
- Responsive layouts
- Fluid animations
- Minimal and polished interactions

The interface is designed to feel like a central digital space rather than a traditional website directory.

---

✨ Experience

Users can explore the ecosystem through:

- Floating project cards
- Interactive website showcases
- Mobile swipe navigation
- Desktop mouse dragging
- Previous/next controls
- Keyboard navigation
- Smooth scrolling
- Subtle background movement
- Direct website access

Each connected website is designed to open independently while remaining part of the larger ecosystem.
